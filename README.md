# mxd-chali · 查理中士兑换按键精灵

在冒险岛怀旧服里，把**灰狼尾巴**之类凑够 100 个、找**天空之城左上角小房子里的查理中士**重复兑换的小工具。
过程固定：**按对话键 → 在窗口里滚轮/拖动 → 按键确认**，一轮一轮重复，直到你按 F9 结束。

只做"按顺序发送键鼠"这一件事：不读画面、不判断有没有换成功、不管掉线。数值（按键名、坐标、
滚轮格数、等待时间）需要你按自己的客户端校准一次，之后就能一直用。

> 兑换规则来自网络问答摘要（100 个狼尾 → 500 经验 + 1 件随机物品，NPC 在天空之城左上角小房子），
> 私服可能改过比例，以你客户端实际表现为准。

## 环境要求

- Windows 10 / 11，Python 3.10 以上（用 Tkinter，不需要装任何第三方库）。
- **本工具和游戏必须同权限运行**。很多私服客户端以管理员权限启动，这时普通权限的程序发的按键会被
  Windows 直接丢弃，表现就是"点了开始完全没反应"。双击 `run.bat` 会自动申请管理员权限。

## 拿到工具

```bash
git clone git@github.com:freedom-lwx/mxd-chali.git
# 没配 SSH 就用 https：
git clone https://github.com/freedom-lwx/mxd-chali.git
```

复制到游戏机后，双击 `run.bat`（或 `python app.py`）就能打开界面。

## 使用顺序

1. **选窗口**：下拉框里选游戏窗口 → 点"用这个窗口"。下面会显示客户区大小和是否在前台。
   如果提示"需以管理员运行"，关掉窗口、双击 `run.bat` 重开。
2. **排动作**：`添加动作 ▾` 依次加 `按键` / `滚轮` / `等待` 等，顺序就是一轮的执行顺序。
   双击某行可以改；上移/下移调顺序。
3. **取点**（滚轮、点击、拖动要用坐标）：点"取点"，把鼠标移到游戏里目标位置，
   3 秒后自动读成客户区坐标。**坐标跟着窗口客户区走，不是屏幕坐标**；窗口大小变了要重新取点。
4. **循环**：`循环次数` 填 `0` = 一直跑到你按 F9；`每轮间隔` 是一轮做完后歇多久。
5. **开始**：点"开始"后有 3 秒给你切回游戏窗口，然后自动跑。运行中可以按 **F9** 或点"结束"停下。
6. **保存配置**：调好一次后点"保存配置"，写到同目录的 `config.json`，下次打开自动载入。

## 动作类型

| 动作 | 参数 | 说明 |
|---|---|---|
| 按键 | 按键名、按住秒数 | 键名写 `enter` / `space` / `esc` / `a` / `1` / `f1` / `numpad0` 等，也认"回车""确定""空格" |
| 等待 | 秒数 | 单纯等一下 |
| 移动鼠标 | X、Y | 只移动不点（一般用不上，滚轮/点击会自己先移动） |
| 滚轮 | X、Y、格数 | 正数向上滚，负数向下滚；每格 120 单位 |
| 点击 | X、Y、左/右键、次数 | |
| 拖动 | 起点、终点、左/右键、时长 | 按住键从起点拖到终点 |

每个动作还有"之后等待(秒)"，用来给游戏反应时间。

## 还没校准的参数

仓库里的 `config.example.json` 只是**占位示例**，按键名和坐标都没核对过。需要按真实客户端校准的：

1. 打开和查理中士对话要按什么键；
2. "滑轮拖动"到底是滚轮滚几格，还是按住左键拖滚动条；
3. 确认兑换按什么键、按一次换几组；
4. 兑换后有没有"获得经验/物品"提示框要关，按什么键；
5. 一直循环到尾巴用完，还是固定轮数。

## 自检与测试

```bash
python scripts/selftest_input.py   # 开个小窗口当靶子，验证键盘/滚轮/点击真能送到窗口
python scripts/check.py            # 单元测试 + 导入检查 + SendInput 结构体大小
```

自检脚本不碰游戏：它会先抢前台，抢不到就提示你点一下自检窗口；每次发送前都会确认目标窗口在前台。
如果自检提示"本工具是普通权限"而前台是管理员权限的窗口，请用管理员权限重跑。

## 已知限制

- **固定序列**：不识别画面。尾巴用完、弹窗没关、人物被推走、掉线、过图，工具都不会知道，
  只会照着顺序继续发。轮数和每轮间隔要按实际留足余量。
- **必须前台**：游戏窗口不在前台会立刻停下并提示（这是故意的，避免按键发到别的窗口）。
- 不记录、不判断兑换结果；不看背包、不读经验。
- 只适合固定分辨率的窗口化客户端；全屏独占能不能收到键鼠没有验证过。

```
chali_macro/gui.py      Tkinter 单页界面
scripts/check.py        单元测试 + 导入检查
scripts/selftest_input.py  输入自检
tests/                  单元测试
```
