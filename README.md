# mxd-chali · 查理中士兑换按键精灵

在冒险岛怀旧服里，把**灰狼尾巴**之类凑够 100 个、找**天空之城左上角小房子里的查理中士**重复兑换的小工具。

一轮的固定流程（已确认）：

1. 按 **y** 3 次（开到兑换窗口）；
2. **滚轮向下** N 格，滚到灰狼尾巴那一行；
3. **点击**兑换；
4. 按 **y** 2 次（关掉领取提示）。

其中 N 和两个鼠标坐标跟客户端相关，需要在游戏机上量一次：格数用界面上的**量滚轮**按钮，坐标用**取点**按钮。
量完存成 `config.json`，以后只要双击 `run.bat` 就能一直跑。

本工具只做"按顺序发送键鼠"这一件事：不读画面、不判断有没有换成功、不管掉线。

> 兑换规则来自网络问答摘要（100 个狼尾 → 500 经验 + 1 件随机物品，NPC 在天空之城左上角小房子），
> 私服可能改过比例，以你客户端实际表现为准。

## 环境要求

- Windows 10 / 11，Python 3.10 以上（用 Tkinter，不需要装任何第三方库）。
- **本工具和游戏必须同权限运行**。很多私服客户端以管理员权限启动，这时普通权限的程序发的按键会被
  Windows 直接丢弃，表现就是"点了开始完全没反应"。双击 `run.bat` 会自动申请管理员权限。

## 拿到工具

```bash
git clone git@github.com:freedom-lwx/mxd-chali.git
# 没配 SSH 就用 https：
git clone https://github.com/freedom-lwx/mxd-chali.git
```

复制到游戏机后，双击 `run.bat`（或 `python app.py`）就能打开界面。

## 使用顺序

1. **选窗口**：下拉框里选游戏窗口 → 点"用这个窗口"。下面会显示客户区大小和是否在前台。
   如果提示"需以管理员运行"，关掉窗口、双击 `run.bat` 重开。
2. **排动作**：`添加动作 ▾` 依次加 `按键` / `滚轮` / `等待` 等，顺序就是一轮的执行顺序。
   双击某行可以改；上移/下移调顺序。
3. **取点**（滚轮、点击、拖动要用坐标）：点"取点"，把鼠标移到游戏里目标位置，
   3 秒后自动读成客户区坐标。**坐标跟着窗口客户区走，不是屏幕坐标**；窗口大小变了要重新取点。
4. **循环**：`循环次数` 填 `0` = 一直跑到你按 F9；`每轮间隔` 是一轮做完后歇多久。
5. **开始**：点"开始"后有 3 秒给你切回游戏窗口，然后自动跑。运行中可以按 **F9** 或点"结束"停下。
6. **配置自动保留**：增删改动作、改循环、改坐标都会**自动写回 `config.json`**，下次打开直接接着用。
   只有这一套配置，没有备份、多套或历史记录；关闭窗口时也会存一次。
7. **量滚轮**：工具栏 `量滚轮…` 按 3 次对话键后每 1.2 秒向下滚 1 格，按 F9 停下并**直接写进滚轮动作**（详见下节）。

## 两种发送方式

窗口上方有个开关 **后台发送（不要求游戏窗口在前台）**：

| | 前台按键（默认） | 后台发送 |
|---|---|---|
| 游戏窗口 | 必须在前台，切走立即停 | **可以不在前台**，你可以同时干别的 |
| 原理 | `SendInput`，和真键盘鼠标一样 | `PostMessage` 直接往窗口投键鼠消息 |
| 风险 | 不会误发 | 游戏客户端不认窗口消息时**完全没反应**（不会报错） |

后台模式能不能用取决于客户端，**试一次就知道**：打开这个开关，点开始，看游戏里有没有动。
没反应就关掉开关改回前台模式（两种模式的键位、坐标完全一样）。窗口最小化时后台模式通常不生效。
`python scripts/selftest_background.py` 可以先验证“消息本身发得对”（不碰游戏）。

## 动作类型

每个动作都能填 **次数**（连做几遍）和 **每两次之间**，所以"y 连按 3 次"是**一个动作**，不用拆成三行。

| 动作 | 参数 | 说明 |
|---|---|---|
| 按键 | 按键名、按住秒数、次数、间隔 | 方向键 `up` / `down` / `left` / `right`（也认"上""下""左""右"）、`enter` / `space` / `esc` / `tab` / `a` / `1` / `f1` / `numpad0`、修饰键 `shift` / `ctrl` / `alt`；按住最长 5 秒（可以按住方向键走一段） |
| 等待 | 秒数 | 单纯等一下（没有次数） |
| 移动鼠标 | X、Y | 只移动不点（一般用不上，滚轮/点击会自己先移动） |
| 滚轮 | X、Y、格数 | 正数向上滚，负数向下滚；每格 120 单位 |
| 点击 | X、Y、左/右键、次数 | 次数就是连点几下 |
| 拖动 | 起点、终点、左/右键、时长 | 按住键从起点拖到终点 |

每个动作还有"之后等待(秒)"，用来给游戏反应时间。

## 第一次用：量三个数

仓库里的 `config.example.json` 已经是上面那个 4 步流程（`y ×3` → 滚轮 → 点击 → `y ×2`），
只有两个鼠标坐标和滚轮格数是占位值（按 1366×768 算的窗口中间），需要在游戏机上量一次。

1. **选窗口** → 点"用这个窗口"。
2. **取两处点**：双击"滚轮"那一行动作 → 点"取点" → 3 秒内把鼠标移到游戏里**物品列表区域** →
   自动记下坐标。同样双击"左键点"那一行动作，取"兑换按钮"的位置。
3. **量滚轮**：站在查理中士旁边（兑换窗口先关掉）→ 点工具栏 `量滚轮…` → 5 秒内切回游戏 →
   它会自己按 3 次 y 打开窗口，然后**每 1.2 秒向下滚 1 格**并写日志；
   **看到灰狼尾巴那一行就按 F9**，日志会写"按 F9 停在第 N 格"，并**直接把这个格数写进滚轮动作**（自动保存）。
4. **试跑一轮**：`循环次数` 设成 1 → 开始 → 看它是不是换成功一次。
5. **正式跑**：`循环次数` 改回 0（一直跑）→ 以后直接开始，配置已经是现在这一套了。

> 量滚轮用的是表里**第一个按键动作的键名**和**第一个滚轮动作的坐标**，所以先要把坐标取对，
> 否则滚轮会滚到别的区域。

## 自检与测试

```bash
python scripts/selftest_input.py      # 前台模式：开个小窗口当靶子，验证键盘/滚轮/点击真能送到窗口
python scripts/selftest_background.py # 后台模式：自建 Win32 探针窗口，验证 PostMessage 打包和投递
python scripts/check.py               # 单元测试 + 导入检查 + SendInput 结构体大小
```

自检脚本不碰游戏。前台自检会先抢前台，抢不到就提示你点一下自检窗口；每次发送前都会确认目标窗口在前台。
如果提示"本工具是普通权限"而前台是管理员权限的窗口，请用管理员权限重跑。
后台自检不需要任何窗口在前台，验证的是消息格式（扫描码、滚轮 delta、点击坐标）。

## 已知限制

- **固定序列**：不识别画面。尾巴用完、弹窗没关、人物被推走、掉线、过图，工具都不会知道，
  只会照着顺序继续发。轮数和每轮间隔要按实际留足余量。
- **前台模式**：游戏窗口不在前台会立刻停下并提示（故意的，避免按键发到别的窗口）。
  不想被这个限制就开"后台发送"，但能不能生效取决于客户端。
- 不记录、不判断兑换结果；不看背包、不读经验。
- 只适合固定分辨率的窗口化客户端；全屏独占能不能收到键鼠没有验证过。
